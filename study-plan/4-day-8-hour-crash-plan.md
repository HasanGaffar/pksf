# PKSF Senior Full-stack — 4-Day, 8-Hour Study Plan

**Exam:** 21 November 2026 · **Preparation window:** 17–20 November · **Daily target:** 8 focused hours.

This is an intensive revision plan, not a prediction of the official exam. Use four 2-hour study blocks with short breaks.

## Daily timetable
| Block | Duration | Work |
|---|---:|---|
| 1 | 2h | Core concepts and notes |
| 2 | 2h | Hands-on coding / SQL |
| 3 | 2h | Written answers and architecture |
| 4 | 2h | Timed practice and error review |

## 17 November — Java and Spring Boot
- 2h: OOP, SOLID, interface vs abstract class, equals/hashCode, collections, generics.
- 2h: Java 8 streams, lambdas, Optional, exceptions, concurrency basics; solve four coding problems.
- 2h: Spring IoC/DI, bean lifecycle, auto-configuration, controller-service-repository, validation, exception handling.
- 2h: JPA/Hibernate, relationships, lazy/eager loading, N+1, transactions, Spring Security.
**Deliverable:** outline a CRUD API and solve four Java problems without notes.

## 18 November — PostgreSQL, SQL, REST and security
- 2h: joins, grouping, subqueries, CTE, window functions, NULL behaviour.
- 2h: indexes, EXPLAIN ANALYZE, transactions, isolation, locks, deadlocks, normalization.
- 2h: HTTP methods/status codes, REST design, pagination, validation, idempotency, error responses.
- 2h: OAuth 2.0/OIDC, Authorization Code + PKCE, JWT validation, RBAC, common OWASP risks.
**Deliverable:** solve eight SQL questions and write a secure API checklist.

## 19 November — React, DevOps and system design
- 2h: JavaScript scope, closure, event loop, Promise, async/await, array methods.
- 2h: React props/state, hooks, effects, forms, API calls, rendering and performance.
- 2h: Docker, CI/CD, Git, Linux, logs/metrics, deployment, backup/restore.
- 2h: DSS design, multi-tenancy, tenant isolation, ingestion, reporting, caching, scaling and disaster recovery.
**Deliverable:** one-page DSS architecture diagram and ten React/JS answers.

## 20 November — Mock tests and revision
- 2h: Mock Test 1 under timed conditions; mark answers.
- 2h: Mock Test 2 under timed conditions; mark answers.
- 2h: Review every wrong/uncertain answer; rewrite weak answers from memory.
- 2h: Final recall of Java/Spring, SQL, HTTP/security and system design. Prepare exam logistics and sleep on time.
If both tests cannot fit, prioritize one complete timed test and use the other block for selected questions.

## 21 November — Exam strategy
- Read the whole paper and allocate time by marks.
- Answer questions you know before getting stuck.
- For coding, state assumptions, handle edge cases and give time/space complexity.
- For system design, draw components, data flow, security boundaries, failure handling and trade-offs.
- Reserve the final five minutes to check omissions.
- JWT alone does not make an application secure: authorization and tenant scope must be enforced server-side.

# PKSF Senior Full-stack Written Exam Preparation

**Exam date:** 21 November 2026 · **Duration:** 2 hours · **Practice target:** 100 marks.

This repository contains original practice questions and model answers for preparation. They are not official PKSF questions and do not guarantee exam coverage.

## Exam blueprint
| Section | Topic | Marks | Repository material |
|---|---|---:|---|
| A | MCQ & Fundamentals | 20 | [500 MCQ with marked answers](question-bank/section-a-500-mcq.md) |
| B | Technical Short Questions | 30 | [500 short Q&A](question-bank/section-b-500-short-qa.md) |
| C | SQL & Coding | 25 | [SQL and coding solutions](question-bank/section-c-sql-coding.md) |
| D | System Design & Architecture | 15 | [System design model answers](question-bank/section-d-system-design.md) |
| E | Problem Solving & English | 10 | [Aptitude and English answers](question-bank/section-e-problem-solving-english.md) |

## Suggested two-hour mock allocation
- A: 20 minutes
- B: 35 minutes
- C: 40 minutes
- D: 15 minutes
- E: 10 minutes

## Study sequence
1. Read Section A and mark uncertain concepts.
2. Write Section B answers from memory before checking the model answer.
3. Solve Section C without looking at solutions; explain complexity and edge cases.
4. Practise Section D using diagrams and explicit security/reliability trade-offs.
5. Practise Section E under time pressure.

## Important senior-level themes
Java/Spring Boot, PostgreSQL, REST, OAuth2/OIDC/JWT, authorization, React/JavaScript, Docker/CI-CD, multi-tenant data isolation, observability, reliability and system design.

See also the existing `study-plan/`, `question-bank/` and `mock-tests/` directories for earlier practice material.
